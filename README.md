# Casio showcase site
```
npm install
npm run dev
```
- `src/data/watches.js`: add or edit watches here
- `src/components/`: one file per section
- `src/styles/global.css`: colors live at the top in `:root`

## Photos
Put licensed photos in `public/images/` named after each watch id (`f91w.jpg`, `a168.jpg`, `ga2100.jpg`, `dw5600.jpg`, `edifice.jpg`, `protrek.jpg`).
Use Casio's official press/media assets or your own photography. Missing files fall back to the CSS illustration.
